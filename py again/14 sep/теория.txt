докер принес контейнеры(изолировное приложения)

контейнеризация - это технология, позволяющая упаковать приложение со всеми компонентами в изолированую 
среду, называемую контейнером. в контейнере нахоиться все: код, библиотеки, зависимости и другого

образ - модель шаблон интрукци, предназначена для создание контейнера. 
конетйнер - это место 

докерфайл это инструкция где каждая строчка новый слой

докеркомпос - средство, для решения задач связаных с использованием нескольких контейнеров
аркестратор управляет контейнерами


докер нужен для того, чтобы упаковать приложение со всеми его
настройками и зависимостями в единый изолированный блок

 FROM — задает базовый родительский образ (например, официальный образ Python или Ubuntu).
 WORKDIR — указывает рабочий каталог внутри контейнера.
 COPY — копирует файлы из вашего компьютера внутрь контейнера.
 RUN — выполняет команды терминала (например, установку пакетов) во время сборки.
 EXPOSE — сообщает, какой порт будет слушать приложение.
 CMD — определяет команду по умолчанию для запуска контейнера




команды образов:

docker image prune -- удаление неиспользуемые образов
